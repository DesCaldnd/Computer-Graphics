# Руководство по OxwaldEngine

Руководство пользователя движка для тех, кто делает на нём игры: программистов геймплея на C++ и Lua и технических художников. Предполагается, что вы знаете C++ и основы разработки игр, но с этим движком раньше не работали.

Каждая глава устроена одинаково: зачем нужна подсистема, ключевые понятия, пошаговые примеры кода, типичные ошибки и ссылки на заголовки API. Почти все примеры на C++ и Lua есть в виде тестов, которые собираются и запускаются, в [`samples/guide_examples/`](../../samples/guide_examples/). Так примеры не расходятся с настоящим API:

```sh
cmake --preset dev -B build/guide -DVCPKG_MANIFEST_INSTALL=OFF \
      -DOX_MODULES="core;scene;physics;animation;spline;audio;ai;net;script;async;world;runtime;samples"
cmake --build build/guide --target ox_guide_examples
ctest --test-dir build/guide -L guide
```

Документация для разработчиков самого движка (архитектура, соглашения, заметки по модулям) лежит в [`docs/dev/`](../dev/ARCHITECTURE.md).
