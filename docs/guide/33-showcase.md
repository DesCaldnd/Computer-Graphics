# 33. Тестовый проект OxwaldShowcase

> **Черновик.** Проект `samples/OxwaldShowcase` сейчас собирается. Структура главы предварительная: названия станций, команды запуска и пути могут измениться. Разделы с пометкой «(будет дописано)» заполним, когда проект будет готов.

## Что это

OxwaldShowcase — демонстрационный проект, в котором собраны возможности движка. Он устроен как набор **станций**: каждая станция — отдельная сцена про одну подсистему со ссылкой на соответствующую главу руководства («Подробнее»). Из хаба можно перейти на любую станцию. Есть автоматическая **экскурсия** (tour): камера облетает все станции по очереди и показывает подписи.

Состав проекта:

| Папка | Что внутри |
| --- | --- |
| `Assets/` | Контент: сцены, префабы, материалы, Lua-скрипты, RmlUi-интерфейс, звук, сгенерированные меши. Список станций — `Assets/Data/stations.json` |
| `Source/` | Нативный игровой модуль `Showcase`: Lua-таблица `showcase`, экскурсия и фоторежим, демо сети (listen server) |
| `Tools/` | `oxshowcase_generate` — пересобирает сцены, материалы и префабы через API движка (таргет `oxshowcase_regenerate`) |
| `Tests/` | Тесты с меткой ctest `showcase` |

Игровой модуль линкуется в OxwaldPlayer и OxwaldEditor и включается только в проектах, где он указан: `"modules": {"Showcase": true}` в `.oxproj`.

## Как запустить в плеере

```sh
OxwaldPlayer --project samples/OxwaldShowcase                 # обычная игра: хаб и станции
OxwaldPlayer --project samples/OxwaldShowcase -- --tour       # экскурсия по всем станциям
```

Аргументы после `--` получает игровой модуль: `--tour`, `--photo`, `--station <id>`, `--shots <dir>`, `--quit`. Собранная версия запускается из пака ([глава 31](31-assets.md)).
